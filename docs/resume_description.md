# 简历项目描述

## 基于安全强化学习的上肢康复机器人自适应导纳控制系统

- 面向平面三自由度上肢康复机器人，构建 MuJoCo 数字孪生和参数化虚拟患者模型，模拟不同肌力、反应延迟、疲劳、噪声和震颤条件下的人机交互。
- 设计分层控制架构，以任务空间导纳控制和独立安全监督器为底层基础，使用 SAC/PPO 或确定性策略低频调整阻尼、辅助增益和速度限制，避免策略直接进入电机控制闭环。
- 实现参数安全投影、变化率限制、交互力/速度保护、通信看门狗和保守参数回退；通过 ROS2 建立仿真/真机统一任务空间接口。
- 基于 FastAPI、WebSocket、React 和规则式 Agent 实现训练交互系统，实时显示轨迹、交互力、导纳参数、患者主动功率、疲劳和安全状态。
- 建立固定导纳、规则自适应、模糊规则、SAC 和 PPO 的多患者对比实验流水线，自动输出逐 episode 数据、统计表、曲线、Markdown 报告和 MuJoCo 演示视频。
