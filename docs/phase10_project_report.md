# 平面三自由度上肢康复机器人安全强化学习系统报告

## 1. 项目概述

本项目面向平面三自由度上肢康复机器人，任务空间为 `[x, y, theta]`，人机交互信号为 `[Fx, Fy, Tz]`。系统采用分层结构：MuJoCo 数字孪生和虚拟患者提供可重复实验环境，固定导纳控制器提供基线，SAC/确定性策略只在低频更新导纳参数，独立安全层负责参数投影、力/速度保护和故障回退。

## 2. 分层架构

1. 机器人层：三关节平面 MuJoCo 模型、正向运动学、IK 和外力接口。
2. 控制层：任务空间三自由度导纳控制、滤波、死区、速度/加速度限幅。
3. 患者层：轻度、中度、重度阻抗患者，包含延迟、噪声、震颤、疲劳和主动功率。
4. 学习层：Gymnasium 环境和 SAC/PPO 参数策略；动作是 `[dDxy, dDtheta, dKa, dlambda_v]`。
5. 安全层：独立参数边界、变化率、状态、交互力和推理异常监督器。
6. 交互/部署层：FastAPI、React、规则 Agent 和 ROS2 任务空间参数接口。

## 3. Phase 10 实验

运行：

```bash
python3 -m scripts.run_phase10_experiments
```

对比方法为固定导纳、规则自适应、模糊规则、SAC 和 PPO；每种方法在轻度、中度、重度虚拟患者上评估。原始数据、聚合数据、图表、训练模型和报告写入 `experiments/reports/phase10/`。

主要指标包括：任务奖励、成功率、安全终止率、平均跟踪误差、峰值/平均交互力、患者主动功率、患者主动做功比例代理、机器人辅助能量和参数振荡率。

## 4. 可复现性

- 所有实验参数集中在 `configs/phase10.yaml`；
- 每个 episode 使用显式随机种子；
- 输出记录配置目录 SHA-256 和 Git commit；
- SAC/PPO 保存模型和 VecNormalize 统计；
- `--quick` 可在新环境中完成短周期端到端验证；
- `ruff`、`mypy`、pytest 和 colcon 分别覆盖 Python/ROS2 验收。

## 5. 安全边界与限制

强化学习和比较策略不直接输出电机力矩、电流或关节命令。真实机器人接入仍需要经过驱动器、机械限位、急停、力矩/速度阈值、零力校准和无人体台架测试。虚拟患者指标是仿真代理量，不能直接解释为临床结论。
